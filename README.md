# MAPS PM prototype
Private internal brainstorm prototype, November 2026.

Buildless static site in `dist/`. Open `dist/index.html` or serve `dist/` with any static web server.

Content is adapted from the supplied business plan and outline. Uses MAPS throughout. Financial forecasts, funding terms, ownership, and compensation information are excluded. Published pricing is labeled draft. Chris's metrics reflect his prior employment, not MAPS's project history. No invented headshot, street address, email address, or legal entity name.

The form validates input and displays a browser-only preview; it sends no data. Navigation, service accordions, and offer-to-contact selections are functional.

Reference design: https://www.hlc-pm.com/ and user-provided HLC HTML/screenshots. Reference photographs and Switzer/Castoro font assets retained for this internal study. Replace reference assets and establish final brand identity before public launch.
